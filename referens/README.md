# Referensmaterial

Här lägger du allt som inspirerar eller styr hur hemsidan ska se ut. Inget i den här mappen visas på sidan.

- `bilder/` – referensbilder (skärmdumpar, foton, mockups, logotyper)
- `inspiration/` – hemsidor och designer du gillar (skärmdumpar eller anteckningar med länkar)
- `dokument/` – texter, PDF:er, varumärkesguide och annat underlag
  - `dokument/designsystem.html` – visuell översikt av hela designsystemet (färger, typsnitt, knappar, kontrastmatris för WCAG AA). Öppna direkt i webbläsaren, eller kopiera koden in i Figma.

Tips: ge filerna beskrivande namn, t.ex. `hero-stil-1.png` eller `farger-palett.jpg`.
